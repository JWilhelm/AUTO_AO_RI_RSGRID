# GW100 data for Figure 4(a–f)

`molecule_errors.csv` contains HOMO/LUMO energies and signed errors for the 10,800 molecule/grid calculations. `aggregate.csv` contains mean and maximum absolute errors in meV; `plot_coordinates.csv` contains the figure values. Each mean includes 100 molecules.

`references.csv` gives the reference energies and paths to the TensorGW outputs. The calculations use aug-SZV-MOLOPT-GTH-tier-2, cluster radii 0.5, 3 and 5 Å, and `EPS_FILTER=1e-12`.
