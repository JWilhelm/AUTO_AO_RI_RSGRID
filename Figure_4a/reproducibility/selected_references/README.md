# TensorGW references for Figure 4(a–f)

This directory contains the LiF, BeO, C7H8 and C6F6 references used for Figure 4(a–f). They use aug-SZV-MOLOPT-GTH-tier-2, the largest matching tabulated RI basis, 30 time/frequency points, `EPS_FILTER=1e-15` and RI-metric regularization `1e-6`. Basis and potential files are in `assets/`.

The full [reference table](../current_gw100/references.csv) identifies the calculation used for every molecule.
