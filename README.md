# AUTO_AO_RI_RSGRID

Calculation inputs and outputs for Figures 1–3 of the original archive
"Optimization of Gaussian basis sets and real-space grids for efficient
low-scaling GW calculations."

The archive's Figure 2 corresponds to Figure 3 of the current manuscript;
its Figure 3 corresponds to the current Figure 4.

## Repository layout

- `Figure_1a/`–`Figure_1f/`, `Figure_2a/`–`Figure_2f/`, and
  `Figure_3a/`–`Figure_3x/` contain the raw CP2K inputs and outputs.
- `TensorGW_Calculations/` contains additional raw calculations.
- `Filter_Controls/H24P64_eps1e-10/` contains the 108-point H24P64
  RI-RS filter check at `EPS_FILTER 1.0E-10`.
- `Plot_Figure_1/`, `Plot_Figure_2/`, and `Plot_Figure_3/` each contain one
  Python script and the PNG and CSV generated by that script.
- `PROVENANCE.json` records the original Noctua directory and checksums for
  every archived calculation and the separate filter controls.

The Si45H56 calculations in `Figure_2c/` and `Figure_2d/` correspond to
Figure 3(c,d) in the current manuscript. Their 24 paired calculations were
repeated on 2026-10-01 with `EPS_FILTER 1.0E-10` using CoopFST. The archived
inputs are the inputs actually run, including the DFT wavefunction restart
from the Noctua source recorded in each input. The corresponding outputs,
provenance checksums, and Figure 2 CSV/PNG were updated together.

The Si45H56 and H24P64 TensorGW references were repeated with
`EPS_FILTER 1.0E-10`. The current values are respectively HOMO/LUMO
`-6.939/-1.118` and `-5.680/-1.890` eV. The Si45H56 RI-RS calculations
at 3 Å in `Figure_3i/` and `Figure_3j/` use `EPS_FILTER 1.0E-10`.
The 108 H24P64 RI-RS calculations at 0.5, 3, and 5 Å in `Figure_3s/`–
`Figure_3x/` use `EPS_FILTER 1.0E-12`; the 1.0E-10 runs are retained in
`Filter_Controls/`. The earlier Si45H56 RI-RS calculations at 0.5 and 5 Å
remain in `Figure_3g/h/k/l` at `EPS_FILTER 1.0E-7`. Their errors in the
updated CSV/PNG use the new TensorGW reference. The Si45H56 5-Å repeat
was cancelled and has not been substituted for those archived results.

## Create the figures and data

Run the scripts from the repository root:

```console
python3 Plot_Figure_1/plot_figure_1.py
python3 Plot_Figure_2/plot_figure_2.py
python3 Plot_Figure_3/plot_figure_3.py
```

Each script reads the archived calculation outputs directly and writes
`Figure_N_created.csv` and `Figure_N_created.png` from the calculations.
Matplotlib is required.
