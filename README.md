# AUTO_AO_RI_RSGRID

Calculation inputs and outputs for the current GWP41 manuscript figures.
The archive's original Figure 1 data also underlie part of current Figure 2;
its original Figure 2 is now Figure 3, and its original Figure 3 is now Figure 4.
The panel directories and plot workflows below follow the current manuscript.

## Repository layout

- `Figure_1a/`–`Figure_1f/`, `Figure_3a/`–`Figure_3f/`, and
  `Figure_4a/`–`Figure_4x/` contain raw CP2K inputs and outputs.
- `Fixed_References/Si293H172_RI-RS_reference/` preserves the raw input and
  output that define the fixed Si293H172 HOMO/LUMO reference
  `-6.029/-2.657` eV. It is retained separately so that Figure 3(e,f) and
  Figure 4 use the same reference after their panel calculations are updated.
- `TensorGW_Calculations/` contains additional raw reference calculations.
- `Filter_Controls/H24P64_eps1e-10/` contains the 108-point H24P64
  RI-RS filter check at `EPS_FILTER 1.0E-10`.
- `Plot_Figure_1/`, `Plot_Figure_3/`, and `Plot_Figure_4/` each contain one
  Python script and the PNG and CSV generated by that script.
- `PROVENANCE.json` records original Noctua directories and checksums.
  Its `audit` block describes the initial import; `entries`,
  `reference_entries`, and `revisions` record the current files and updates.

The Si45H56 Figure 3(c,d) calculations in `Figure_3c/` and `Figure_3d/`
were repeated on 2026-10-01 with `EPS_FILTER 1.0E-10` using CoopFST.
The Si293H172 Figure 3(e,f) calculations in `Figure_3e/` and `Figure_3f/`
were repeated on 2026-10-02 with `EPS_FILTER 1.0E-10` using single-node
LargeMEM jobs with DFT wavefunction restart. Each panel contains the 18
AUTO_RI and six tabulated-RI points. The fixed reference above is unchanged.

The Si45H56 and H24P64 TensorGW references were repeated with
`EPS_FILTER 1.0E-10`. Their HOMO/LUMO values are respectively
`-6.939/-1.118` and `-5.680/-1.890` eV. The Si45H56 Figure 4(i,j)
calculations in `Figure_4i/` and `Figure_4j/` use `EPS_FILTER 1.0E-10`.
The 108 H24P64 Figure 4(s–x) calculations in `Figure_4s/`–`Figure_4x/`
use `EPS_FILTER 1.0E-12`; the 1.0E-10 runs are retained in
`Filter_Controls/`. The Si45H56 Figure 4(k,l) 5-Å calculations were repeated as a complete
36-point series at `EPS_FILTER 1.0E-10` using the original TensorGW
CP2K build. The old 1.0E-7 inputs and outputs were removed from these
active panels; Git history preserves them. The 0.5-Å Figure 4(g,h)
calculations still use `EPS_FILTER 1.0E-7`.

## Create the figures and data

Run the scripts from the repository root:

```console
python3 Plot_Figure_1/plot_figure_1.py
python3 Plot_Figure_3/plot_figure_3.py
python3 Plot_Figure_4/plot_figure_4.py
```

Each script reads archived outputs directly and writes its
`Figure_N_created.csv` and `Figure_N_created.png` from the same points.
Matplotlib is required.
