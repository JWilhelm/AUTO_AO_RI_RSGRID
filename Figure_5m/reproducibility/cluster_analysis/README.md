# Cluster data for Figure 5(g–r)

`points.csv` contains the HOMO/LUMO energies, reference values, plotted errors in meV, RI/RS ratios, filter and Tikhonov settings, and calculation paths for Si45H56 and H24P64. Paired HOMO/LUMO panels use the same calculations. A 1 meV floor is applied to the plotted errors for logarithmic display.
