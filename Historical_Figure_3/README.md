# Previous GW100 Figure 3 data

This directory preserves the full GW100 Figure-3 inputs and outputs before
the October 2, 2026 replacement with the Figure-4(c,d) RS/AO=7 slice.
The historical script also reads the unchanged silicon all-radius data from
the repository root. Its CSV/PNG reproduce the prior all-radius comparison;
use `Plot_Figure_3/` for the current manuscript plot.

The historical optimized GW100 series and the new Figure-4 slice differ in
RI neighborhood and/or grid initialization. Do not splice the historical
RI/AO=1 or 1.5 values into the current curve.
